# Отсутствующий Git при сборке backend image с Jev runtime extra

**Дата:** 2026-09-23 22:46 UTC
**Файлы:** `backend/Dockerfile`
**Серьёзность:** низкая

## Проблема

GitHub Actions job `packaging` падал при сборке backend Docker image. Установка зависимостей завершалась ошибкой `Git executable not found` для pinned зависимости `jevcal`, которую включает production extra `jev`.

## Корневая причина

`jevcal` устанавливается из конкретного Git commit, но Dockerfile устанавливал только `poppler-utils`. `uv` использует системный Git для получения VCS-зависимости; в базовом `python:3.11-slim` Git отсутствовал.

## Решение

Добавлен Git как временная build dependency рядом с Poppler. После `uv sync --frozen --no-dev --extra jev` Git удаляется через `apt-get purge --auto-remove`, поэтому он нужен только на этапе разрешения pinned `jevcal` и не остаётся в итоговом runtime image. Шаг сборки пишет безопасные `[FIX]` сообщения о начале и завершении установки VCS-зависимости.

## Предотвращение

- При добавлении Git-based Python dependency проверять, что все среды установки (включая Docker image) имеют системный Git.
- Держать инструменты сборки отдельно от runtime packages и удалять их из итогового image, когда приложение не вызывает их во время работы.
- Сохранять сборку production Docker image в CI как regression gate для optional production extras.
